# Решения по DEM и геоданным

## 2026-11-14 — Компактная сетка CTX для планировщика

- Источник: USGS Mars 2020 Science Investigation CTX DEM Mosaic, файл Jezero, 20 м/пиксель.
- Использовать CRS исходного GeoTIFF: Mars 2000 Sphere, собственная equirectangular projection Jezero, метры. Не назначать EPSG:4326 и не применять земное преобразование координат.
- Географические точки из проектной таблицы трактовать как планетоцентрические широты и восточные долготы, согласно метаданным продукта; проектировать формулой spherical equirectangular с параметрами, считанными из CRS.
- Экспортировать квадратный фрагмент 75×75 нативных ячеек вокруг точки `roi_center`; без ресэмплинга. Сохранять высоты Float32 little-endian и отдельную валидность/NoData mask.
- Числа высот — метры; вертикальная привязка к MOLA control net по каталогу USGS. NoData брать только из GeoTIFF mask/NoData, не выводить из цвета или экстремумов.
- Сетка 20 м не разрешает отдельные небольшие камни. Подготовка данных не подтверждает проходимость или безопасность EVA.

## 2026-11-14 — Расширенный участок для демо-карты

- Увеличить текущую веб-карту с 1,5 × 1,5 км (75 × 75) до 7,5 × 7,5 км (375 × 375) вокруг прежнего центра.
- Оставить CTX DEM на нативном шаге 20 м без пересэмплинга; контрольные точки остаются внутри окна.
- Пересобрать оптическую подложку USGS CTX из того же ортофотоплана, совместив её с новым охватом при 5 м/пиксель (1500 × 1500).
- Новое покрытие показывает более широкий контекст Езеро; расчёты остаются ограничены разрешением этой DEM и не гарантируют безопасность маршрута.

## 2026-11-14 — Глобальный обзор Марса в веб-карте

- Добавить над локальной картой Езеро глобальный обзор на основе NASA Mars Trek MGS MOLA Colorized Shaded Relief.
- Использовать глобальный обзор для контекста планеты и положения района; расчёты высот и маршрутов остаются на отдельной локальной CTX DEM.
- Отметить, что глобальный слой является цветной картой рельефа, не фотографией; продукт MOLA не покрывает полярные области выше 88° широты.
- Сохранить в репозитории обзорную карту мира для автономного старта; уровни приближения 0–7 загружать по мере необходимости из NASA Mars Trek WMTS. Для подробных уровней требуется интернет.
- Езеро остаётся демонстрационным районом, выбранным командой по доступности данных; официальное задание принимает любую локацию или маршрут на Марсе.

## 2026-11-14 — Режимы глобальной карты

- Добавить переключение между MOLA shaded relief, MGS MOC Atlas visible-light mosaic и Viking VIS MDIM 2.1 color mosaic по официальным NASA Mars Trek WMTS.
- Для каждого режима соблюдать собственный формат и верхний уровень WMTS: MOLA jpg до 7, MOC png до 6, Viking jpg до 7.
- Сохранить MOLA обзор как автономный fallback; при переключении на спутниковую или цветную мозаику не подмешивать рельеф в пустоты покрытия, чтобы не создавать ложное впечатление сплошного слоя.
- Добавить разворачивание глобальной карты на весь экран для просмотра крупных деталей.
