# Кратер Гейла — второй район локального планирования MarsPath

## Научные данные (проверено 15 ноября 2026 г.)

**Продукт:** [USGS Astrogeology — Mars MSL Gale Merged DEM 1m, version 3](https://astrogeology.usgs.gov/search/map/mars_msl_gale_merged_dem_1m).

**Официальный числовой GeoTIFF:** https://planetarymaps.usgs.gov/mosaic/Mars/MSL/MSL_Gale_DEM_Mosaic_1m_v3.tif

**Авторы/организации:** Timothy Parker, Fred J. Calef III; NASA/JPL-Caltech, USGS Astrogeology Science Center, University of Arizona. Мозаика объединяет HiRISE и CTX (NASA MRO), HRSC (ESA Mars Express), со связью с MOLA. Исходный шаг 1 м/пиксель, полный файл ~3,6 ГБ. Отсчёты исходной DEM имеют разную локальную точность; исходная публикация указывает привязку к MOLA control net, а не сантиметровую точность.

**Местоположение:** выбран компактный квадрат в районе посадки Curiosity, центр по округлённым координатам посадки из имеющегося каталога NASA PDS ODE: **4,59° S, 137,44° E**. Это центр области анализа, **не** утверждение о сантиметрово или метрово точном месте посадки. Точки A/B в `metadata.json` — произвольные DEM-ячейки для демонстрации, **не** подтверждённые стоянки Curiosity.

**Подготовка:** `scripts/preprocess_gale_dem.py` напрямую читает действительные высоты исходного USGS GeoTIFF. Берётся квадрат **251 × 251 ячеек** с выходным шагом **20 м** и охватом **5,02 × 5,02 км**. Каждый выходной пиксель — среднее действительных значений исходной **1-метровой** сетки; это **не** нативная DEM с шагом 20 м. Сохраняются `heights.f32` (little endian), `mask.u8`, `metadata.json`, `checksums.sha256`.

Параметры проекции **не переносятся из Езеро**: GeoTIFF имеет собственный Mars 2000 Sphere / equirectangular, радиус 3 396 190 м, планетоцентрическую широту, восточную долготу; выводимый affine и стандартная параллель читаются из исходного CRS. Применение земного EPSG:4326 запрещено.

### Воспроизведение ETL

При доступе к GeoTIFF с локального диска:

~~~powershell
python -m pip install -r requirements.txt
python scripts/preprocess_gale_dem.py --source "C:\\mars-data\\MSL_Gale_DEM_Mosaic_1m_v3.tif"
~~~

При поддержке HTTP range на сервере и в локальном GDAL:

~~~powershell
python scripts/preprocess_gale_dem.py
~~~

Вторая команда читает источник по `/vsicurl/`, не скачивая все 3,6 ГБ полностью. Не гарантируется на каждом компьютере, зависит от сети и поддержки GDAL.

Отчёт ETL и компактные файлы должны появиться в `public/data/gale/` **только после успешного фактического чтения USGS**. При отсутствии файлов интерфейс честно отключает расчёт; подложки MOLA/CTX не используются как числовые высоты.

### Проверка геоданных

- `metadata.json`: `region_id = gale_crater_curiosity_demo`, `grid.width = grid.height = 251`; `pixel_size_m = [20,20]`; Mars-native WKT и ненулевая доля действительных ячеек.
- `heights.f32`: 251 × 251 × 4 = **252 004 байта**, `mask.u8`: 63 001 байт.
- `source.source_sha256`: SHA256 **компактного** `heights.f32 || mask.u8`, **НЕ** исходного многогигабайтного GeoTIFF. Область хеширования явно записана в `source.hash_scope`.
- Модель ограничена разрешением 20 м; нельзя считать, что одиночные камни или микрорельеф обнаруживаются на исходном разрешении 1 м.
- Визуальная карта региона `/data/mars-global/regions/gale-crater/` остаётся отдельным обзорным слоем. Числа берутся **только из** `public/data/gale/`.

### Проверка интерфейса

1. Открыть 3D-глобус и выбрать **«Кратер Гейла»**.
2. Сохранить существующие карту и научные слои; **ниже** появится отдельный блок числовой DEM и построения маршрутов.
3. Нажать **«Готовые A/B»** или указать на локальном рельефе собственные A и B, затем **«Построить 2 маршрута»**.
4. Проверить зеленый кратчайший A* и оранжевый вариант A* с демонстрационным штрафом за уклон; если пути совпадают — показать это без выдуманного обхода.
5. Измерение профиля и уклонов использует настоящие высоты в ячейках; ссылки на источник всегда видимы.
6. Проверить масштабирование, перемещение карты, отклонение NoData, смену маршрута, работу на разных размерах окна и доступность клавиатуры.

**Ограничения:** прототип не сертифицирован для безопасности EVA; никакие пороги NASA не применены. Опорная глобальная регистрация данных не означает точность каждого 20-метрового пикселя на местности.
