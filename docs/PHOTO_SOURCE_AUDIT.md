# Проверка источников фотографий Perseverance

Дата проверки: 14 ноября 2026 года.

## Короткий вывод

Фотографий очень много, и их можно каталогизировать. В NASA Raw Images есть фильтры по солу, дате и камере, миниатюры, ссылки на оригиналы и загрузка выбранных снимков. В доступной JSON-записи есть уникальный идентификатор снимка, сол, дата, код камеры, подпись, авторство, ссылки на файлы, а также номер site/drive и часть данных ориентации/модели камеры.

В первой проверенной странице из 100 записей NASA JSON не было широты и долготы. Поэтому этот каталог позволяет отбирать и показывать фотографии, но сам по себе не даёт готовую точку цели для каждой фотографии.

## Оценка объёма

На 14.11.2026 официальный JSON-каталог NASA по категории Perseverance (`mars2020`) сообщает:

- `total_results`: **579 518 записей** по миссии;
- верхний сол в доступной галерее: **2031**;
- при фильтре по солам 0–1796: **520 794 записи**.

В NASA Photojournal есть публикация о выезде ровера далеко к западу от кратера на соле 1797. Поэтому диапазон 0–1796 использован только как **приблизительная оценка периода работы в районе Езеро**, а не как точный географический подсчёт: часть записей нужно сверять по фактическим координатам маршрута. Каталог NASA содержит больше одной формы счётчика (`total_results` и `total_images`); в этом отчёте `total_results` означает количество записей, возвращённых списком, а не число уже проверенных уникальных мест на карте.

Официальные источники для повторной проверки:

- [NASA Raw Images: галерея Perseverance](https://mars.nasa.gov/mars2020/multimedia/raw-images/index.cfm)
- [NASA Raw Images JSON: записи миссии, солы 0–1796](https://mars.nasa.gov/rss/api/?feed=raw_images&category=mars2020&feedtype=json&ver=1.2&num=1&page=0&order=sol+desc&condition_1=mars2020%3Amission&condition_2=0%3Asol%3Agte&condition_3=1796%3Asol%3Alte)
- [NASA Photojournal: Perseverance за пределами кратера на соле 1797](https://science.nasa.gov/photojournal/nasas-perseverance-rover-snaps-westernmost-selfie/)

NASA Raw Images позволяет фильтровать снимки по камере и солу, показывать уменьшенные версии и выбирать несколько файлов для загрузки. Исходники могут быть очень большими: у одной опубликованной NASA панорамы JPEG занимает 24 МБ, а TIFF — 463 МБ. Для веб-карты следует использовать миниатюры или уменьшенные версии, а оригиналы открывать по ссылке.

## Какие данные есть и как привязать снимок

### 1. Точка ровера — можно показать как место съёмки

В JSON NASA есть номера `site` и `drive`, но в проверенной записи нет широты/долготы. Их можно связать с данными маршрута ровера и PDS Rover PLACES / Analyst's Notebook. Такая метка означает **где стоял ровер**, а не где находится объект в кадре.

### 2. Направление/область съёмки — возможно вычислить, но потребуется обработка

В JSON-примере присутствуют некоторые данные камеры и её ориентации. В PDS-архиве для Mars 2020 хранятся более полные исходные, калиброванные и производные данные, а PDS labels описывают геометрию снимка. Чтобы получить контур видимой поверхности, нужно соединить данные снимка с координатами ровера, моделью камеры и марсианской системой координат; затем пересечь направление взгляда с поверхностью.

PDS Analyst's Notebook умеет искать данные по солу, месту и прибору. Однако его справка указывает, что готовые контуры фотоснимков сейчас поддерживаются для Curiosity (MSL), а Perseverance (M20) запланирован позже. Следовательно, для Perseverance готового слоя контуров пока недостаточно: расчёт привязки придётся реализовать или проверять отдельно.

### 3. Примерная цель или без координат

PDS описывает известное и приблизительное положение цели: снимок с того же места/положения ровера даёт более надёжную привязку; для соседних мест положение цели приблизительное, а неопределённость растёт с расстоянием. Для части снимков, например неба, а также для продуктов без нужной геометрии контур вообще нельзя рассчитать. Составная панорама может быть подписана районом и солом, но без проверенной координаты её центра.

Для каталога использовать отдельное поле `location_kind`:

- `rover_station` — координата стоянки ровера; не обозначает цель в кадре;
- `approximate_footprint` — область/направление кадра, вычисленные с явно описанными допущениями;
- `unknown` — достоверной координаты нет.

Не назначать уровень точности по одной только подписи, названию района или номеру сола.

## Источники и ограничения

- [NASA Raw Images](https://mars.nasa.gov/mars2020/multimedia/raw-images/index.cfm) — удобная галерея, фильтры по солу/дате/камере, миниатюры и загрузка. JSON endpoint используется для автоматизированного каталога; это не замена PDS-архиву.
- [NASA PDS: архив Mars 2020](https://pds-geosciences.wustl.edu/missions/mars2020/index.htm) — приборные архивы, данные и документация. Release 16 охватывает солы 1740–1859; данные выпускаются отдельными пакетами, поэтому полный PDS-архив обновляется реже оперативной галереи.
- [PDS Mars 2020 Analyst's Notebook](https://an.rsl.wustl.edu/m20/) — просмотр по солу, месту и прибору.
- [Справка PDS по положению научных целей](https://an.rsl.wustl.edu/help/Content/Using%20the%20Notebook/Concepts%20and%20deep%20dive/Targets.htm) — различает известное и приблизительное положение цели.
- [Справка PDS по контурам снимков](https://an.rsl.wustl.edu/help/Content/Using%20the%20Notebook/Concepts%20and%20deep%20dive/Data%20product%20footprints.htm) — объясняет расчёт контуров, ограничения и текущую поддержку MSL.
- [Справка PDS по камерам Mars 2020](https://pds-geosciences.wustl.edu/m2020/urn-nasa-pds-mars2020_mission/document_camera/Mars2020_Camera_SIS_Labels_sort_pds.html) — документирует поля меток и камерную геометрию.

## Практический вывод для MarsPath

- Потенциальный каталог — сотни тысяч записей, поэтому нельзя загружать все оригиналы в веб-приложение.
- Начинать стоит с выборки Perseverance по участкам и камерам, используя NASA API для поиска, а PDS — для проверки положения.
- На карту наносить маркер стоянки ровера там, где координаты подтверждены; контур кадра добавлять только после геометрической проверки.
- Показывать соседние уровни уверенности разными символами. Для неизвестных координат оставить фотографию в каталоге/галерее, не придумывая точку.
- Пилот на 400 записей показал, что фотографию часто можно показать у подтверждённой стоянки или приблизительного центра site. Он не измеряет долю точных контуров кадра по всему архиву. Полная классификация и подсчёт по конкретным записям выполняются при сборке каталога фотографий (следующая задача); не обещать геопривязку каждой из полумиллиона записей.
## Проверка координат ровера в PDS PLACES

Дополнительно проверен официальный [Mars 2020 Rover PLACES Bundle](https://pds-geosciences.wustl.edu/missions/mars2020/places.htm). Он содержит локализации ровера. PDS сообщает, что Release 16 охватывает данные PLACES по 1897-й сол. Файл `best_interp.csv` имеет поля `frame`, `site`, `drive`, планетоцентрическую широту/долготу, высоту, ориентацию, SCLK и сол.

В этом файле найдено 31 752 записи с `frame=ROVER`, солами 0–1792 и числовыми координатами широты/долготы/высоты. Максимальный сол в выгруженной таблице — 1792. Это количество позиций ровера в файле, **не число фотографий**; видимый разрыв с описанным в PDS охватом Release 16 нужно отдельно выяснить.

Проверена связка NASA Raw JSON и PLACES на 400 записях: взято по 100 результатов с четырёх страниц (offset 0, 1300, 3000, 5000) внутри солов 0–1796, сортировка по солу от новых к старым. У 200 записей `site/drive` напрямую совпали с координатами `ROVER`; у 200 координаты нашлись только на уровне `SITE`; у 0 в этой выборке не нашлось даже координат `SITE`. Это не случайная выборка и результат нельзя переносить как процент на все 520 794 записи. Для `drive=0` или отсутствующей пары нужна проверка по времени/SCLK и локализации PDS.

Практическая классификация для дальнейшей выгрузки:

| Класс | Что отображаем | Как подтверждать |
|---|---|---|
| Стоянка ровера подтверждена | Маркер места аппарата во время съёмки | Сопоставить время/SCLK снимка с координатами PLACES; сохранить точность исходной локализации |
| Кадр привязан примерно | Направление или контур видимой поверхности | Использовать метаданные камеры/направления и пересчитать пересечение с поверхностью; явно указать допущения |
| Координат нет | Только фотография в списке/галерее | Не ставить маркер; причина — нет локализации, нужной геометрии или это составное изображение без точной позы |

PDS также предупреждает, что рассчитанные контуры кадров — приближение: плоская поверхность, неизвестный рельеф вдали и ошибка координат ровера влияют на результат. Готовая функция контуров сейчас перечислена только для Curiosity (MSL); Perseverance (M20) в плане добавления.

## Опубликованный пилотный каталог

В `public/data/jezero/photos.json` опубликован первый проверенный набор из семи материалов Perseverance. Каталог не требует отдельного сервера и загружается обычным `fetch` в React. Для каждой записи сохранены уникальный идентификатор, название, подпись, миссия, камера, солы, подтверждённые земные даты (если они прямо указаны NASA), авторство, страница NASA/JPL, изображение, веб-миниатюра и отдельные источники метаданных/изображения/координат.

В пилоте шесть записей имеют `location_type=approximate_area`. Их координаты взяты из ближайшей доступной локализации ровера в официальном PDS Rover PLACES, а не из положения объекта в кадре. Поле `localization_sol` и пояснение позволяют увидеть расхождение между солом фотографии и локализацией. Эти точки нельзя переименовывать в `exact_rover`, пока SCLK или site/drive конкретного изображения не сопоставлены с PLACES.

Многосольная панорама дельты имеет `location_type=none`, `coordinates=null` и `sources.coordinates=null`: составному продукту из пяти солов не назначена выдуманная одиночная точка. Неизвестные земные даты также оставлены пустым массивом, а не восстановлены приблизительно из номера сола.

`web/photoCatalog.ts` проверяет каталог при загрузке: уникальность ID, допустимые типы привязки, диапазоны марсианских координат, согласованность `none`/`null`, HTTPS и разрешённые официальные домены NASA/JPL/PDS. `web/photoCatalog.test.ts` проверяет опубликованный файл и негативные случаи.

## Отображение на подробной карте

Подробная карта загружает каталог напрямую в React и проецирует координаты через ту же марсианскую систему координат, что и DEM. На текущем участке 7,5 × 7,5 км отображаются пять приблизительных фототочек. Близкие точки объединяются в экранные кластеры; при увеличении радиус кластеризации уменьшается и становятся видны отдельные отметки. Фильтры ограничивают выборку по точному названию камеры и включительному диапазону солов.

Панорама PIA24921 не имеет единственной координаты и остаётся в отдельном списке без маркера. Точка снимка Sol 1039 имеет проверенную приблизительную позицию ровера, но находится западнее текущего покрытия DEM; она также показывается в списке без маркера с явной причиной. Карта не переносит такие записи на границу и не создаёт фиктивных координат. Нажатие на одиночную отметку или запись списка открывает миниатюру, подпись, камеру, солы, даты, авторство, тип привязки и ссылки NASA/JPL.
